# Video Stream Project Setup

## 1. Create Project Directory
```powershell
# Navigate to your user directory
cd C:\Users\lebas

# Create and enter project directory
mkdir video-stream
cd video-stream

# Verify you're in the correct directory
dir package.json  # This should show the package.json file
```

## 2. Install Dependencies
After you're in the correct directory, run:
```powershell
npm install
```

## 3. Start Development Server
Once the installation is complete, start the development server:
```powershell
npm run dev
```

## Troubleshooting
- If you see "command not found" for npm, make sure Node.js is installed
- If you get file not found errors, verify you're in the correct directory
- If you need help, just ask and I'll guide you through the process

Please follow these steps in order and let me know if you encounter any issues!
